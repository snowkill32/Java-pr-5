# Практическая работа №5

Дженерики и обобщённое программирование. Структуры данных. Стек.

- `part1` — удаление дубликатов, линейный поиск, поиск максимума в одномерном и двумерном массивах.
- `part2` — обобщённый стек на массиве и стек с наследованием от `ArrayList`.
- `part3` — `MyStack` с композицией и наследованием, проверка копирования списка.
- `uml` — диаграммы классов. Отчёт DOCX содержит код и результаты запусков.

## Запуск

Требуется JDK 8 или новее. Компилируйте исходники в UTF-8 с сохранением структуры пакетов.

| Часть | Класс с методом main |
| --- | --- |
| part1 | `generics.TestGenerics` |
| part2 | `arraystack.TestArrayStack` |
| part2 | `liststack.TestGenericStack` |
| part3 | `inheritance.TestMyStack` |
| part3 | `composition.TestClone` |
